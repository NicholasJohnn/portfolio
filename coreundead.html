CoreUndead

2024 · Solo project · 5 weeks · UEFN

Action Adventure / Shooter · Game Design, Level Design, Combat Design, Set Dressing, Lighting

CoreUndead is a single-player fantasy shooter and my first complete game in UEFN (Unreal Editor for Fortnite). I took it from the first design document all the way to a published, playable island.

What I did

  • Wrote the Game Design Document (GDD) and Level Design Documents (LDDs)
  • Designed the game loop, level layout and combat encounters
  • Built all gameplay with UEFN creative devices
  • Blocked out, set dressed and lit the entire level
  • UEFN
  • Unreal Engine
  • Photoshop
Play in Fortnite (opens in a new tab) Read the breakdown

Design highlights

  • A glowing cube is visible from every part of the map, always pulling players toward the goal
  • Unique "special trees" act as landmarks so players never lose their bearings
